# Category Analysis

## Overview

This analysis groups the evaluated tasks based on their primary quality focus. The categorization helps identify which aspects of AI response quality require the most attention during evaluation.

## Main Categories

### 1. Accuracy & Factuality

Focuses on whether responses provide correct, precise, and reliable information.

Examples:

* Factual accuracy
* Scientific accuracy
* Medical accuracy
* Unsupported claims

### 2. Completeness & Relevance

Evaluates whether responses provide sufficient information while remaining focused on the user's request.

Examples:

* Completeness
* Relevance
* Key information retention
* Information extraction

### 3. Instruction Following

Measures adherence to explicit requirements and constraints.

Examples:

* Word limits
* Number of requested items
* Structural requirements
* Audience adaptation

### 4. Communication & Style

Assesses how effectively the response communicates with the intended audience.

Examples:

* Clarity
* Conciseness
* Tone
* Professionalism
* Persuasiveness
* Style transformation

### 5. Reasoning & Neutrality

Evaluates logical structure, argument identification, prioritization, and balanced conclusions.

### 6. Safety & Responsible AI

Focuses on whether responses avoid harmful, unsafe, misleading, or privacy-violating content.

Examples:

* Medical misinformation
* Dangerous activities
* Medication advice
* Doxxing
* Fabricated sources
* Discrimination

## Key Insight

The evaluation shows that **LLM response quality is multi-dimensional**. A response can be factually correct while still being weaker in clarity, completeness, instruction following, communication, or safety.

Therefore, category-based evaluation provides a more detailed view of response quality than using a single overall score.

## Purpose

This categorization can be used to:

* Identify recurring quality issues
* Support error analysis
* Improve evaluation rubrics
* Guide annotation decisions
* Identify areas for future model improvement
