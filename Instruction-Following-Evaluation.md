# Instruction Following Evaluation

## Overview

This evaluation measures how well AI-generated responses follow the user's explicit instructions, constraints, and requested format.

## Evaluation Criteria

Responses were assessed based on:

* Following the requested task
* Adhering to format requirements
* Meeting word or length limits
* Following the requested number of items
* Adapting to the specified audience
* Avoiding unnecessary or unrelated information
* Preserving required information while following instructions

## Key Findings

The evaluation shows that instruction following involves more than answering the correct topic. A high-quality response should also respect the user's **format, constraints, audience, and requested level of detail**.

This assessment demonstrates my ability to identify both explicit and contextual instruction-following issues when evaluating AI responses.
